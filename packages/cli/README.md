# codechart

The codechart CLI: maps and flowcharts of code changes, and of how existing code works, for AI coding agents, in terminal, chat and HTML.

```bash
npm i -g codechart && codechart install-skill
```

See the [repository README](https://github.com/MiscomLab/codechart#readme) for install, features, configuration and docs. The shared engine lives in [`@codechart/core`](../core).
